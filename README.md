# 🎮 Gameteca

My private gallery for save project videos.<br>
_...for me, and friends Discord 2023._

## Structure

- **`media/`** – Multi-media photos and videos from project.
- **`scripts/`** – Render pages function.
- **`styles/`** – Page style/Responsiviness.


## Viewing project

Open <a href="www.https://gameteca.vercel.app">Gameteca</a> in the browser for viewing my project gallery.
